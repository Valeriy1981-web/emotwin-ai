# EmoTwin AI — Эмоциональный Цифровой Двойник

> "ИИ, который помнит, как вы чувствовали, а не только что вы говорили."

EmoTwin AI — первый в мире сервис, создающий цифрового двойника на основе вашей эмоциональной памяти: переписки, голосовых, дневников, фото.  
Не имитация. Не копия. Эмоциональное ядро личности.

---

## 🚀 Цели проекта

* Помочь людям понять себя в кризисе
* Сохранить эмоциональное наследие для близких
* Создать персонального ИИ-коуча, который знает вашу историю чувств

---

## 🛠 Технологии

### Backend
* **FastAPI** — для создания API
* **Python** — основной язык разработки
* **PostgreSQL** — база данных
* **Redis** — кэширование

### AI Модели
* **NLP** — анализ текста
* **Audio Analysis** — обработка голоса
* **Image Processing** — анализ изображений
* **OpenAI API** — интеграция с GPT

## 🛠 Установка

### Требования
* Python 3.9+
* Docker (опционально)

### Запуск

```bash
# Клонирование репозитория
git clone https://github.com/Valeriy1981-web/emotwin-ai.git

# Установка зависимостей
pip install -r requirements.txt

# Копирование файла конфигурации
cp .env.example .env

# Запуск сервера
uvicorn main:app --reload
