# EmoTwin AI — Эмоциональный Цифровой Двойник

> "ИИ, который помнит, **как вы чувствовали**, а не только что вы говорили."

EmoTwin AI — первый в мире сервис, создающий цифрового двойника на основе **вашей эмоциональной памяти**: переписки, голосовых, дневников, фото.  
Не имитация. Не копия. **Эмоциональное ядро личности.**

---

## 🚀 Цели
- Помочь людям **понять себя** в кризисе
- Сохранить **эмоциональное наследие** для близких
- Создать **персонального ИИ-коуча**, который знает вашу историю чувств
