# Примеры данных (анонимизированные)

Эти файлы используются **только для тестирования и обучения моделей**.

## Доступные сэмплы:

### chat_sample.txt
* Формат: текстовый файл
* Структура: диалог между двумя пользователями
* Пример содержимого:
[USER1]: Привет! Как дела?
[USER2]: Всё хорошо, спасибо!

### voice_sample.mp3
* Формат: аудиофайл
* Параметры:
* Битрейт: 128 kbps
* Частота дискретизации: 44100 Hz
* Длительность: 1 минута

### journal_2024-05-01.txt
* Формат: текстовый файл
* Структура:
* Дата в формате YYYY-MM-DD
* Текст записи
* Пример:
2024-05-01
Сегодня был хороший день…

## Важные примечания

⚠️ **Конфиденциальность данных**:
* Реальные пользовательские данные **никогда не хранятся** в репозитории
* Все примеры созданы искусственно или анонимизированы
* Данные используются только для тестирования и разработки

## Рекомендации по использованию

1. **Тестирование моделей**:
* Использовать данные для проверки корректности работы
* Проверять обработку различных типов данных
* Тестировать граничные случаи

2. **Обучение моделей**:
* Использовать данные для начальной настройки
* Проверять качество обработки
* Оценивать точность результатов
