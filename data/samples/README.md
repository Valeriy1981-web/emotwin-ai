# Примеры данных (анонимизированные)

Эти файлы используются **только для тестирования и обучения моделей**.

## Доступные сэмплы:
- `chat_sample.txt` — переписка (имена заменены на [USER1], [USER2])
- `voice_sample.mp3` — голосовая заметка (без распознавания личности)
- `journal_2024-05-01.txt` — запись из дневника

⚠️ **Важно!**  
Реальные пользовательские данные **никогда не хранятся в репозитории**.  
Все примеры созданы искусственно или анонимизированы.
